# 手柄操作

用户已报告手柄可用，但尚未提供型号、接口及按键映射，以下按 Batocera 的常见配置说明。

## 退出游戏

多数模拟器使用 **Hotkey + START** 返回 Batocera 游戏列表：按住 Hotkey，再按 START。

Hotkey 通常配置为 **SELECT / BACK**，也可能映射为 **HOME / LOGO**，以设置手柄时选择的按键为准。不能直接假定所有手柄的 SELECT 都是 Hotkey；忘记映射时，在 Batocera 的手柄设置中检查或重新配置。

部分独立模拟器使用自己的退出方式或菜单，不保证全部都遵循上述组合。如果无效，先记录游戏所属平台、模拟器、手柄型号和 Hotkey 映射，再核对该模拟器设置。
