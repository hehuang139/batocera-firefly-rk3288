# 传输游戏与 BIOS

Batocera 使用对应模拟器支持的游戏文件。把 Windows `.exe` 安装程序复制进去不能直接安装或运行；先按目标平台准备文件，再放到对应目录。

用户已确认这块板 eMMC 启动成功、手柄可用；现场有线 SSH 登录已验证，SHARE 已扩容至约 10.5 GiB。下面的游戏文件传输流程尚未在本次现场单独验证。

## 有线与 Wi-Fi

修正设备树及 AP6335 板级 NVRAM 后，板载 Wi-Fi 已通过一次软件重启后的自动恢复、扫描及系统网络列表验证。目前尚未关联路由器，无线接口没有 IP，也未通过 Wi-Fi 传游戏，详见 [Wi-Fi 修复与验证](WIFI.md)。当前有线 SSH 已验证可连通，可先使用有线网络。

无线配置入口为 **START → 网络设置**：启用 Wi-Fi，填写路由器的 SSID 和密码，确认连接成功后读取实际 IP。电脑连接同一路由器即可，电脑用网线或 Wi-Fi 均可；文件共享和 SFTP 的路径与有线连接相同。扫描到网络本身不代表已经取得 IP 或能传文件。

## Windows 局域网共享

1. 将电脑和开发板接入同一局域网，首次建议使用网线。
2. 在 Batocera 的网络设置中读取板子的实际 IP 地址。
3. 打开 Windows 文件资源管理器，在地址栏输入 `\\板子的IP\share\roms`，把“板子的IP”替换为实际地址。
4. 把游戏文件复制到对应平台的目录，例如：

| 平台 | 共享目录下的文件夹 | Batocera 内路径 |
| --- | --- | --- |
| NES / FC | `nes` | `/userdata/roms/nes` |
| SNES / SFC | `snes` | `/userdata/roms/snes` |
| PlayStation | `psx` | `/userdata/roms/psx` |

各目录中的说明文件以及模拟器文档列出支持的扩展名。多文件光盘游戏要保留所需文件及相对路径；不要仅复制索引文件而漏掉其引用的内容。

## 共享打不开时使用 SFTP

先核对板子 IP、电脑与板子的网络连接。遇到 Windows 共享权限或连接问题，可以使用 WinSCP：

- 文件协议：`SFTP`。
- 主机名：从板子网络设置读取的 IP。
- 端口：`22`。
- Batocera 默认用户名 / 密码：`root` / `linux`；若改过密码，使用实际密码。需要时在 Batocera 设置中启用 SSH。
- 游戏目录：`/userdata/roms`，再进入对应平台子目录。

网络传输失败时先保留报错，再检查网络和 Batocera 服务状态。

## BIOS 与刷新游戏列表

需要 BIOS 的模拟器，将对应 BIOS 文件放到 `/userdata/bios`，Windows 共享路径为 `\\板子的IP\share\bios`。文件名、校验值和所需子目录以对应模拟器要求为准，可在 Batocera 的 BIOS 检查界面查看缺失项。

复制完成后，在 Batocera 主界面按 **START → 游戏设置 → 更新游戏列表**。再打开相应平台测试游戏；若没有显示，先检查目录和扩展名；若显示但打不开，检查 BIOS、游戏文件完整性及模拟器要求。功能反馈方法见 [测试记录](TESTING.md)。
